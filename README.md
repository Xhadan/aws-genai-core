# aws-genai-core

Production architecture implementations, orchestration modules, and evaluation harnesses for Amazon Bedrock and AWS Generative AI services. Structured sequentially across the 5 official domains of the AWS Certified Generative AI Developer - Professional (AIP-C01) exam.

## Repository Architecture

- **Domain 1**: Foundation Model Integration, Data Management, and Vector Stores
- **Domain 2**: Implementation and Integration (Bedrock Agents, AgentCore, ReAct Loops)
- **Domain 3**: AI Safety, Security, and Governance (Bedrock Guardrails, PII Redaction)
- **Domain 4**: Operational Efficiency and Optimization (Prompt Caching, Token Reduction)
- **Domain 5**: Testing, Validation, and Troubleshooting (RAGAS, LLM-as-a-Judge, FMEval)
